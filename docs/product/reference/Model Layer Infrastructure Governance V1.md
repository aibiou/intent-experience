# Model Layer Infrastructure Governance V1｜模型层基础设施规范

> 定位：模型层是本产品**纯基础设施**——它提供能力、不参与体验决策。
> 用户（体验者）在体验中应**感知不到模型层的存在**；模型配置是**开发者/管理员行为**，只在配置页发生。
> 本规范约束「配置 → 路由 → 使用」三段的职责边界与纪律，防止模型层打扰用户。

---

## 1. 定位与总原则

1. **基础设施化**：模型层（对话 LLM / 图像 / 语音 / 视频生成）对外只呈现「该模态当前可用」，不呈现「哪个模型、哪个提供方、什么 key」。
2. **运行时不打扰**：体验流内**禁止任何模型选择 UI**；一切生成/对话自动使用「该模态当前启用配置」，用户无感。
3. **配置即开发期行为**：模型配置只在 `/config` 页发生，属于开发者/管理员操作；配置后即时生效，无需重启。
4. **可审计、可回退**：任何配置变更都有隐私确认记录与启用/停用开关；火山系配置保留为备用，一键可切回。

---

## 2. 三层职责分离

| 层 | 位置 | 职责 | 面向 |
|---|---|---|---|
| **配置层** | `/config` 页 + `config-store`（密文持久化） | 增删改启用各模态提供方；预设一键填充；隐私六要素确认；key 密文保存 | 开发者/管理员 |
| **路由层** | `llm-gateway`（对话）+ `generation-gateway`（图/音/视频） | 按模态自动选择启用配置；契约路由自动匹配（OpenAI 兼容 / Seedance / Agnes / 智谱 / 豆包语音）；失败错误映射与退避 | 内部 |
| **体验层** | 首页 / 体验流 / 创作工作台 | 只调用「该模态当前可用」，不接触模型与 key；失败给可行动的人性化文案 | 用户 |

---

## 3. 运行时无感规则（体验层纪律）

1. **体验流禁止模型选择**：对话与生成请求一律不带 `model_id`，由路由层取该模态启用配置（`getEnabledProviderConfigForModality`）。现有实现已符合（experience-screen 生成请求体无 `model_id`）。
2. **生成失败文案人性化**：`humanizeGenerationFailure` 统一映射——主行可行动（"稍后再试" / "换种说法"），提供方细节仅作次要行；不把状态码/内部错误甩给用户。
3. **未配置才提示**：`unconfigured` 状态仅在「该模态尚无启用配置」时出现，文案引导去 `/config`（唯一入口）；已配置则全程无感。
4. **创作工作台可选但不打扰**：`/create` 的模型下拉仅列出该模态**已启用**配置，默认选中启用项；显示中文提供商标识 + 模型名，不暴露英文内部键。
5. **契约自动匹配**：同一模态多提供方（如视频 Seedance / Agnes / 智谱）由 `isSeedanceContract` / `isDoubaoVoiceContract` 等按模型名与端点域自动路由，用户不感知。

---

## 4. 配置体验规范（好配置）

1. **唯一入口**：`/config`。模态分组（文本/语音/图像/视频，每类至多启用一条）；统计徽标显示各模态配置数。
2. **预设一键填充**：`PROVIDER_PROFILES` 提供已验证预设（阿里云百炼 / 火山引擎 / 豆包语音），点击即填端点+默认模型；预设非准入，任意 OpenAI 兼容提供方可自定义。
3. **识别模型**：`识别模型` 按钮向端点 `/models` 拉取可选模型，免手抄模型 ID（不支持该接口的提供方可手动填）。
4. **中文标签**：提供商标识友好化（火山引擎 / Agnes AI / 豆包语音 / 本地网关 NewAPI / 阿里云百炼），配置页与创作页共用同一映射。
5. **隐私与安全**：启用前须隐私六要素再确认（留存确认记录）；API key 仅以 AES-256-GCM 密文持久化（加密密钥经环境变量注入、与密文分离），明文仅运行期内存、不进日志/证据产物/git。
6. **当前生效一目了然**：头部状态徽标显示「当前生效：提供方 · 模型」；启用条目标记绿色高亮 +「当前回应由该配置的模型生成」。

## 5. 当前默认矩阵（2026-10-13）

| 模态 | 默认提供方 | 模型 | 用途 |
|---|---|---|---|
| 文本 | Agnes | agnes-3.0-flash | 对话/体验流 |
| 图像 | Agnes | agnes-image-2.5-flash | 绘画生成 |
| 视频 | Agnes | agnes-video-2.5-flash | 视频生成 |
| 语音 | 火山·豆包语音 | seed-audio-1.0（2.0 音色库） | 朗读生成 |

备用（停用态，配置页一键启用可切回）：火山引擎文本（doubao-seed-2.0-lite）、图像（seedream-4.5，2K 画幅）。
接入纪律：新增提供方先实测可用（Python 直连验证真实错误码），再入预设；未开通/未达额度不写入默认。

---

## 6. 提供方接入与治理

1. **OpenAI 兼容优先**：对话/图像走 chat-completions / images-generations 兼容契约；非兼容协议（豆包语音 X-Api-Key、Seedance 异步任务）以**契约路由分支**适配，绝不动摇 OpenAI 兼容主干。
2. **模型配置与产品决策解耦**：产品代码不写死任何提供方/模型 ID；预设与记录均为数据，路由按记录执行。
3. **密钥分离**：加密密钥（`EXPERIENCE_CONFIG_ENCRYPTION_KEY`）经环境变量注入，与密文、代码分离。
4. **验证标准**：模型层代码变更须过 `tsc`（core + full 0 错误）+ 产品链路实测（`/api/generate` 该模态真实出产物）；配置变更即时生效。
5. **不打扰边界**：新增任何「选择模型 / 切换提供方 / 填写 key」类 UI 到体验层即视为违规，一律放配置层。
