## 2. 裁决项（产品负责人填写区）

### D-01 切片内跨会话持久化载体形态

**背景：** 授权 §2(4) 要求跨会话主题 / 意图信号持久化，但运行时现为进程内会话级状态（`state-store.ts`；PD-07"S1 不持久化跨会话数据"纪律在 F-5 被授权 §2(4) 取代性扩展）。切片内载体形态无 frozen 源定义。

**选项 A（推荐·切片内本地持久化记忆记录存储）：** F-5 在运行时内新增轴外持久对象——记忆记录存储（memory record store），切片内以本地持久化载体承载（文件载体或等效机制），默认仅合成数据（ADR-0002 §3 证据沙箱硬边界不变）；记录 schema 依 D-02；生产形态存储治理按隐私六要素已批准方向（cn / 阿里云 / 云存储）执行，属生产部署治理、不属本切片实施范围。先例：F-2 创作对象 / F-4 分支记录的轴外持久化纪律。

**选项 B（仅会话内记忆）：** 记忆不跨会话，F-5 仅实施生命周期语义与纠正 / 撤回。问题：与授权 §2(4) 明文"跨会话主题 / 意图信号持久化"冲突——不可选。

**选项 C（外部存储服务接入）：** 切片内接入外部存储服务。问题：超出切片范围、引入外部依赖与真实数据风险（授权 §5.1 隐私护栏）——不可选。

**裁决区（产品负责人 2026-10-09 填写）：** **选项 A（切片内本地持久化记忆记录存储）**。理由：授权 §2(4) 明文要求跨会话持久化，frozen 源无切片内载体定义；轴外持久对象 model on F-2 创作对象 / F-4 分支记录纪律；隐私六要素（cn / 阿里云 / 云存储）为生产治理方向、不属切片实施范围；选项 B 与授权 §2(4) 明文冲突，选项 C 引入外部依赖与真实数据风险（授权 §5.1）。日期：2026-10-09。

### D-02 记忆记录模型与生命周期状态机（语义定义裁决）

**背景：** 授权 §2(4) 生命周期"记住 → 暂时使用 → 逐渐失效 → 被用户纠正 → 被用户撤回"须契约化；07 §10 五态（OBSERVED → CANDIDATE → ACTIVE → DECAYING → EXPIRED；显式 EXPLICIT → ACTIVE）为 frozen 源形态；07 §17 纠正 / §15 用户控制为操作源。记录 schema 与事件词表无契约定义。

**选项 A（推荐·五阶段生命周期契约化 + 轴外记忆子状态机 + 四事件词表）：** 记忆记录为轴外持久对象（五分量：record_id / 内容分量（主题或意图信号，07 §4 形态）/ 生命周期状态 / 创建与更新时间戳 / 来源与置信度分量）；生命周期状态机（轴外，体验阶段轴不变）：REMEMBERED（记住，创建即进入）→ IN_USE（暂时使用，经 RECALL 操作）→ DECAYING（逐渐失效，时间衰减驱动）→ EXPIRED（到期，自动）；用户操作 CORRECT（被用户纠正：内容更正 + 纠正留痕，状态回到 REMEMBERED）与 WITHDRAW（被用户撤回：→ EXPIRED + 撤回留痕 + 删除审计）。记忆域事件词表（domain=`memory`，C6 §7 已预留）：`memory_recorded` / `memory_corrected` / `memory_withdrawn` / `memory_expired`（状态变更操作留痕；衰减为内部置信度更新，不逐点发事件；检索为只读，不发事件——07 §16 透明性经事件日志 + 用户控制面承载）。07 §10 五态映射：OBSERVED/CANDIDATE 合并于 REMEMBERED 创建（行为推断默认不直接成为长期记忆，07 §10 纪律；S2 内无长期记忆，候选→长期路径不存在）。

**选项 B（二态简化 ACTIVE / EXPIRED）：** 问题：与授权 §2(4) 明文五阶段生命周期冲突（"暂时使用 / 逐渐失效 / 被用户纠正 / 被用户撤回"阶段缺失）——不可选。

**选项 C（行为推断自动晋升长期记忆）：** 问题：与 07 §10"行为推断默认不直接成为长期 Memory"及 PD-23"长期记忆 S2 不启用"冲突——不可选。

**裁决区（产品负责人 2026-10-09 填写）：** **选项 A（五阶段生命周期契约化 + 轴外记忆子状态机 + 四事件词表）**。理由：授权 §2(4) 五阶段生命周期明文；07 §10 / §17 / §15 为操作源；记忆域事件词表承载于 C6 §7 已预留 ‘memory’ 层；纠正 / 撤回留痕满足 PD-23“用户显式纠正 / 撤回记录”与 07 §16 透明性；选项 B 与授权 §2(4) 五阶段冲突，选项 C 与 07 §10“行为推断默认不直接成为长期记忆”及 PD-23 冲突。日期：2026-10-09。

### D-03 记忆的作用面与检索接口面

**背景：** 记忆如何影响下一次体验：07 §21 优先级链 L0 Current Turn > L1 Experience State > L2 Current Intent > L3 Current State > L4 Session Context > L5 Relevant Short-term Memory > L6 Relevant Long-term Memory；07 §12 Current Intent 覆盖；07 §20 检索纪律（只取相关信息）；07 §22 检索不应改变体验。切片内 Context Builder 集成面未定义。

**选项 A（推荐·L5 信号注入 + Current Intent 覆盖不变 + 检索只读）：** 记忆仅作为 Context Builder 的 L5 相关短期记忆信号注入（按 07 §20 纪律：以当前意图为检索键，只取相关记录，不全量塞入）；L2 Current Intent 覆盖 L5（07 §12 不变式）；记忆检索为只读操作，不改变体验、不触发任何产品动作（不启动新体验、不自动续行、不修改创作状态）；L6 长期记忆层在 S2 不存在（负向不变式）。

**选项 B（记忆可覆盖当前意图）：** 问题：违反 07 §12 覆盖链与 GS-04 用户主权（记忆不得替用户决定当前意图）——不可选。

**选项 C（记忆自动触发体验动作）：** 问题：违反 07 §22 与"不应发生"清单（记忆 / Analytics 不得触发产品动作）——不可选。

**裁决区（产品负责人 2026-10-09 填写）：** **选项 A（L5 信号注入 + Current Intent 覆盖不变 + 检索只读）**。理由：07 §21 优先级链与 §12 覆盖链为 frozen 源不变式；07 §20 检索纪律（只取相关信息）与 §22“检索不应改变体验”直接转写；选项 B 违反 07 §12 与 GS-04 用户主权，选项 C 违反 07 §22 与“不应发生”清单。日期：2026-10-09。

### D-04 保留期限起算与删除执行（隐私要素联动裁决）

**背景：** 隐私要素 1（保留至少 6 个月）+ 要素 5（到期自动删除 + 删除审计记录，与要素 1 联动——到期日可计算、删除可验证）；PD-23（默认 6 个月后自动删除）；07 §11 时间衰减（短期兴趣必须衰减）。起算点与衰减参数无规范定义。

**选项 A（推荐·最后更新起算 6 个月 + 到期自动删除 + 删除审计 + 示例参数规范化）：** 保留期自记录最后更新时间起算（默认 6 个月——活跃记忆不因持续使用而意外过期；产品负责人保留版本化调整权）；到期自动删除并登记删除审计记录（删除时间 / 记录范围 / 验证信息，要素 5"删除可验证"）；时间衰减采纳 07 §11 示例形态为规范参数（指数衰减：Day 0 = 0.90 → Day 3 ≈ 0.63 → Day 14 ≈ 0.25 → Day 30 ≈ 0.08；用户再次主动探索时 interest ↑ 重新获得证据，07 §11 纪律）；衰减至阈值以下驱动 DECAYING → EXPIRED 迁移。

**选项 B（创建起算 6 个月）：** 问题：活跃使用的记忆因创建时点过期而丢失，与"跨会话保留最近发生过、可能对下一次体验有帮助的信息"（07 §4）目的相悖——不推荐。

**选项 C（永久保留或会话级保留）：** 问题：分别违反隐私要素 1/5 与跨会话持久化义务——不可选。

**裁决区（产品负责人 2026-10-09 填写）：** **选项 A（最后更新起算 6 个月 + 到期自动删除 + 删除审计 + 示例参数规范化）**。理由：隐私要素 1（至少 6 个月）/ 要素 5（到期自动删除 + 删除审计记录——到期日可计算、删除可验证）与 PD-23（默认 6 个月）联动；最后更新起算避免活跃记忆意外过期（07 §4 跨会话保留目的）；07 §11 示例形态采纳为规范衰减参数；选项 B 与 07 §4 目的相悖，选项 C 分别违反隐私要素 1/5 与跨会话持久化义务。日期：2026-10-09。

### D-05 写入路径与单一写入者（接口面裁决）

**背景：** 授权 §5.8：Minimal Memory 写入不得绕过 Runtime 单一写入者；模型提出 `state_update` 时 Validator / Runtime 拒绝（GS-06）。用户纠正 / 撤回（07 §13"别再给我这个" / §14"我喜欢这个" / §17 Memory Correction）的入口面须定义。

**选项 A（推荐·运行时内部写入 API + 用户动作路由）：** 记忆写入仅经 Runtime 内部写入方法（单一写入者纪律 model on `state-store.ts`）；模型输出不得直接写记忆（Validator 拒绝 `state_update` 类提案，GS-06 / CC02 H05 不变式）；用户纠正 / 撤回作为用户动作经分类 / 路由进入记忆域操作（确定性规则词表识别，model on F-4 D-03 纪律），经 Runtime 单一写入者执行并留痕（`memory_corrected` / `memory_withdrawn` 事件）；写入侧执行 07 §7 不默认长期记住清单过滤（临时情绪 / 一次性兴趣 / 一次性任务 / 当前环境 / 单次拒绝 / 推测人格不得写入）。

**选项 B（模型可提议记忆写入经 Validator 校验后生效）：** 问题：与 GS-06"模型提出 `state_update` 时拒绝"冲突——不可选。

**选项 C（前端 / 外部通道直接写入）：** 问题：违反 Runtime 单一写入者（CC02 H01）——不可选。

**裁决区（产品负责人 2026-10-09 填写）：** **选项 A（运行时内部写入 API + 用户动作路由）**。理由：授权 §5.8 明文（写入不得绕过 Runtime 单一写入者；模型 state_update 拒绝，GS-06）；用户纠正 / 撤回经确定性规则词表识别（model on F-4 D-03 纪律）经单一写入者执行并留痕；写入侧执行 07 §7 过滤；选项 B 与 GS-06 冲突，选项 C 违反 CC02 H01。日期：2026-10-09。

## 3. policy_v1.5.0 变更文本草案（分层；D-01…D-05 全项选项 A 时生效）
