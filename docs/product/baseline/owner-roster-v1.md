## 2. 填写与生效规则

1. 填入姓名即表示该人接受该行的职责与签署义务；电子签署须附日期与所依据的文档版本/哈希。
2. 人选为 PENDING 的行，其对应 Gate 事项保持 NOT PASSED / BLOCKED，不因本名册存在而改变。
3. 角色兼任（含"用户本人兼任全部角色"）合法，但每一行仍须单独签署并声明冲突；角色 5（独立评测）与任何实现作者身份冲突时，须在 G5 前换人或书面记录隔离措施。
4. 本名册是登记工具：它不解锁 G1，也不构成 CR-08 的关闭——CR-08 在各角色完成对应签署后才可更新状态。
