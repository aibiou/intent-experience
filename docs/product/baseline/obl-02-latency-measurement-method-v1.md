# 延迟测量方法定义（OBL-02）

**编号：** OBL-02-LATENCY-METHOD-01
**版本：** 1.0.0（APPROVED——产品负责人 2026-10-09 按 E3 批准（OBL-02 处置，decision-register v0.19.0 / PD-21 批准包）；批准范围仅测量方法，不含任何统计阈值（PB-03 / PD-08））
**起草日期：** 2026-10-09
**来源：** G5 第 9 项 DEFERRED（2026-10-09，P3-S1-G5-WORKSHEET-01 v1.7.0）；OBL-02（decision-register v0.16.0 / v0.18.0）
**效力边界：** 本文件只定义测量方法（分层与样本窗口纪律），不定义统计阈值。无真实用户基线前不编造阈值（PB-03 / PD-08）；S1 运行耗时仅登记为参考值。面向公开发布的统计 Gate 须另行预先定义人群、观察窗口、分子/分母、数据源、阈值和批准人（E3 §发布门槛），并经产品负责人批准。

## 1. 测量对象

- 提交接受到流完成（submission accepted → stream done）的墙钟时间（每次提交单独登记）
- 首内容分块延迟（TTFB：提交接受到首个内容分块）
- 分块间隔分布（chunk-to-chunk）
- 故障恢复路径单列（LLM_UNAVAILABLE → 健康重试完成），不与正常路径混合

## 2. 环境分层

- 执行形态：进程内证据形态（in-process）与 HTTP 形态（Next.js 路由端到端）分别登记，不合并
- 运行时：Node.js v24.21.0（F-2 精确锁定）；Next.js 16.4.0 / React 19.3.0 / TypeScript 7.0.2
- 平台：登记 OS / CPU / 内存；证据运行仅使用合成数据（ADR-0002 §3）
- 网关：当前仅合成网关（`SyntheticLlmGateway`）；真实提供方接入须另经产品决策与隐私六要素批准，接入后按第 3 节分层

## 3. 模型分层

- 当前：合成网关无真实模型——模型维度登记为 N/A（synthetic）
- 真实提供方接入后：按提供方 / 模型标识 / 模型版本分层；跨模型评测责任链由角色 3 与角色 5 共签

## 4. 请求类别分层

- 语义动作：DIRECT_ANSWER / WHY / WHAT_IF_SIMULATE / CHANGE_DIRECTION / STOP（S1 已启用动作集合，PD-05 / PD-06）
- 语义动作补充：P2 关闭切片（PD-21，2026-10-09 批准）新增 CREATE / CORRECTION，实施后纳入本分层单独登记，不与既有类别混合
- 路径：首请求 vs 相邻重复请求；正常 / 负向 / 边界 / 故障恢复四维度（黄金套件维度，P2 Exit Gate §8）
- 每个类别独立登记，不计算混合平均值

## 5. 样本窗口与采集纪律

- 窗口定义：连续执行窗口（单次证据运行内的连续提交序列）；每次运行登记 Run ID、git HEAD、起止时间
- 样本量（方法学建议，非验收阈值）：每类别每形态 ≥ 30 次提交方可计算参考统计量；低于该量仅登记原始值
- 数据源：证据执行器 trace 时间戳（trace_started / 案例事实 / trace_completed）；HTTP 形态经服务端日志
- 同一窗口内不切换运行时版本；环境变更（运行时、依赖、硬件）须重新开窗

## 6. 指标与披露

- 内部参考值：既有运行耗时（如 F2-GS-0001 14.6s、F3-EB-0001 9.0s）已登记为参考值，不构成指标宣称
- 任何延迟指标宣称（均值 / 分位数 / 区间）须同时满足：本方法经产品负责人批准 + 满足第 5 节样本纪律 + 注明形态 / 环境 / 类别分层
- 公开发布：须另行满足 E3 统计 Gate（人群、观察窗口、分子/分母、数据源、阈值、批准人）

## 7. 批准

- 批准范围：仅测量方法（分层与样本窗口纪律）；不含统计阈值（PB-03 / PD-08）
- 批准后约束：任何延迟指标宣称仍须满足第 5 节样本纪律并注明第 2–4 节分层；公开发布仍须另行满足 E3 统计 Gate（人群、观察窗口、分子/分母、数据源、阈值、批准人）
